# ByteArena

ByteArena is an interactive coding platform designed for developers and programming enthusiasts to practice coding problems, participate in programming contests, and improve their problem-solving skills. The platform provides a complete coding experience with secure code execution, automated scoring, problem authoring, editorials, and real-time leaderboards.

## ✨ Features

### 👤 User Authentication

* User registration and login
* Firebase-based authentication
* Personalized user experience

### 💻 Coding Practice

* Browse and solve programming problems
* Difficulty-based problem organization
* Problem search and filtering
* Built-in code editor powered by Monaco Editor
* Custom test case execution
* Secure code submission
* Automated scoring
* Submission history
* Problem editorials

### 🏆 Contest Management

* Create and manage coding contests
* Join contests
* Solve contest problems
* Real-time contest timer
* Submit solutions during contests
* Automated contest scoring
* Real-time live leaderboard

### 📝 Problem Authoring

* Create and manage coding problems
* Add problem descriptions and test cases
* Configure problem difficulty
* Manage problem data for contests and practice

### 👨‍💼 Admin Panel

* Manage users
* Manage coding problems
* Manage contests
* Manage submissions and platform content

## 🚀 Getting Started

Follow these steps to run ByteArena locally.

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/mdalemrananas/ByteArena.git
```

Navigate to the project directory:

```bash
cd ByteArena
```

Install the dependencies:

```bash
npm install
```
### Run the Development Server

Start the application with:

```bash
npm start
```

The application will be available on the local development server.
